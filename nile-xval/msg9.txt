feat: 更名为 Grounded，界面改为英文单语，总览按「已测到什么」重排

三件事一起做，因为它们互相牵连。

## 更名 GeoLook → Grounded

旧名一直在跟产品打架——README、SKILL.md、界面里都得写同一句免责声明
「GEO 指生成式引擎优化，不是地理信息」。名字要靠免责声明才能用对，就是在
消耗解释预算，面向英文用户只会更严重。Grounded 取自 LLM 领域的 grounding
（给模型权威依据），产出的六个编译目标字面上就是 grounding artifacts。

174 处、5 种写法。用哨兵掩码保住了不能动的 URL：geolook.cc、
github.com/aigclink/geolook、ProductHunt 徽章——新域名和新仓库还不存在，
改了就是死链，等域名到位再单独换。

纯字符串替换漏了两处**被 HTML 标签拆开**的写法（`Geo<span>Look</span>`，
在侧栏 logo 和登录页），导致改完侧栏还显示旧名。补了一轮容忍标签与空白的
扫描确认无残留——这类写法值得记住。

## 英文单语

删掉 README.zh-CN.md / README.ja.md、日文截图与演示视频、中文版截图与演示；
英文资产去掉 -en / .en 后缀提升为默认。ULANG 写死 'en'，移除语言切换器与
URL 语言参数，<html lang> 与 <title> 直接写英文（不再运行时覆盖）。

**翻译覆盖层暂时保留**，这是有意的：后端仍产出中文（audit.py 的体检问题、
tasks.py 的工单文案、analytics 的指标标签都经过它），现在删掉这些串会退回
原始中文，比现状更差。后端源串英文化后一并移除——那是下一批的事。

test_ui.py 原本守 WCAG 3.1.1（声明语言必须与内容一致）。规则没变、取值变了，
所以改成守新规则而不是删掉它，并补上「不得再有语言切换入口」的回归。

## 总览按「已测到什么」重排

改之前：9 张卡里 8 张空，整页 1,229 字符。根因不是排版——**每张卡都来自
采样，而采样需要 API key**，可 README 明写零 key 也能跑。于是默认路径在
爬取+体检+工单全部跑完之后，落到的是一个死看板，而此刻真实存在的
17.4 分、四层链卡在访问层、6 条 P0，一样都不露面。

现在 KPI 行跟着实际测到的东西走：无采样时显示体检分、阻塞层、P0 数、
最大抽取块缺口；采样相关的三块（趋势图、引擎表现、竞品分层）收成一张
说明四个指标各是什么、并带「配置 key」与「导出人工采样表」两个按钮的
引导卡。死卡从 8 张降到 2 张，首屏直接给出「Access 层失败 → 下游全部
不可见 → 6 条 P0 在等」。

标题里的后端串用 <span> 单独包裹：覆盖层按完整文本节点匹配字典，拼进
长句就翻不了（改前显示成「访问 layer is failing」）。后端英文化之后这层
包裹会自然失效但不出错。

新增的界面文案直接写英文源串——覆盖层只翻译字典里有的，英文原样透出，
这也是后端英文化迁移的起点。
